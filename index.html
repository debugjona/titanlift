1. Parámetros de Diseño y Datos Iniciales

Anteproyecto Titan-Lift

Condición de Carga y Geometría

  • Carga útil a levantar (Wload): 4 oz (113.4 g = 1.112 N)
  • Material estructural: Filamento PLA
  • Diámetro de elemento (d): 1.75 mm
  • Área transversal (A): A = π·(1.75)2 / 4 ≈ 2.405 mm2

Propiedades Mecánicas del PLA

  • Resistencia a fluencia/tracción (σy): 50.0 MPa
  • Resistencia a cortante (τy): 28.87 MPa (Von Mises: 0.577 · σy)
  • Factor de Seguridad Objetivo (FSdiseño): 2.0

Criterio de Diseño Seguro

Para cumplir un FS = 2.0, los esfuerzos actuantes no deben superar los esfuerzos permisibles:

σperm = σy / FS = 50 / 2 = 25.0 MPa
τperm = τy / FS = 28.87 / 2 = 14.44 MPa

Ecuaciones de Equilibrio Global

∑Fx = 0 ⇒ Ax = 0

∑Fy = 0 ⇒ Ay - Wcounter - Wjib - Wtop - Wmast - Wload = 0

3. Análisis de Esfuerzos por Elemento

Cálculos de Resistencia

Tirantes y Cables

Tipo de esfuerzo: Tracción pura

σ = P / A

σ = 1.112 N / 2.405 mm2 = 0.462 MPa

Pasadores (Cortante Simple)

Tipo de esfuerzo: Cortante directo (1 plano)

τ = V / A

τ = 1.112 N / 2.405 mm2 = 0.462 MPa

Pasadores (Cortante Doble)

Tipo de esfuerzo: Cortante directo (2 planos)

τ = V / 2A

τ = 1.112 N / (2 × 2.405 mm2) = 0.231 MPa

4. Evaluación de Seguridad y Volcamiento

Conclusión de Estabilidad

¿La grúa se cae o se rompe al levantar 4 oz?

NO. La estructura es totalmente estable y segura. No experimentará fallas por rotura del filamento ni colapso de pasadores.

Explicación del Factor de Seguridad (FS)

El FS objetivo era 2.0 (soportar el doble del peso requerido). Sin embargo, los resultados arrojaron valores reales entre FS = 62.5 y FS = 108.2.


Esto significa que el filamento PLA de 1.75 mm posee una capacidad mecánica de 60 a 100 veces superior a las exigencias de levantar 4 oz (113.4 g).

Estabilidad Global y Recomendaciones

  • Momento Flector: La carga es tan baja (1.112 N) que el momento flector generado sobre la torre no provoca riesgo de vuelco ni requiere contrapesos excesivos.
  • Consideración de Pandeo: Aunque el material no falla por tensión/corte, se recomienda asegurar la rigidez lateral en las barras largas a compresión del mástil.
